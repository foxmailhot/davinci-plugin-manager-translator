# 达芬奇插件管理与翻译软件 0.2.0

解压后双击 ResolvePluginManager.exe，无需安装 Python。

## 翻译插件

1. 在插件清单选中一个模块，点击“一键翻译所选插件”。程序提取候选文字，先匹配本地词库与缓存，再调用所选翻译接口。
2. 在“插件翻译”选择服务。MyMemory 无需密钥、有每日额度；Google 网页接口为非官方实验接口；Google Cloud 官方接口需自行配置密钥和账单；也可连接自建 LibreTranslate。
3. 通过“停止翻译”保存当前进度；网络错误、额度不足也会保存已经完成的译文，可随后继续。机器译文可在汉化词库修正，再重新翻译。
4. 核对预览，退出达芬奇和其他宿主，选择“应用至插件（实验）”。程序备份原版并安装翻译适配层。系统目录写入可能需要右键 EXE“以管理员身份运行”。
5. 重启达芬奇检查效果是否正常。出现异常，退出宿主后选择“恢复原版插件”。

实验适配层已经过模拟 OFX 宿主和插件测试，尚未完成真实 BCC/Sapphire 的达芬奇兼容性验证，不能视为全量已验证汉化。适配层替换 OFX 显示标签、提示、分类及选项，转发原插件标识、参数标识、数值和渲染调用。独立编辑器、自绘控件和专用/压缩资源不保证能翻译。静态候选可能包含内部和未使用文字，候选译文数量不等于界面覆盖率。

应用与禁用会影响所有共享此模块的 OFX 宿主。程序检测 Resolve.exe；其他宿主请自行关闭。一个模块可能包含多个效果，本版尚不能单独选取模块内某一个效果。

## 管理与恢复

支持扫描公共 OFX 目录、OFX_PLUGIN_PATH 及自定义目录。可搜索、筛选、导出当前结果。禁用前复制备份、校验 SHA-256，再将模块改名为 .ofx.disabled-by-resolve-manager；恢复在“备份与恢复”页操作。文件存在不代表宿主加载和许可证校验通过。

已经汉化再禁用的模块，请先从“备份与恢复”启用，再恢复原版翻译。

## 手动更新

点击右上角“检查更新”，从本项目 GitHub 最新正式 Release 检查版本。确认后下载并校验更新包，随后启动新版；保留旧 EXE，共用本地设置、词库与备份。更新不覆盖旧程序，新版位于本地数据目录的 updates 中。没有公开 Release 时会提示暂无可用版本。不会启动时自动联网检查或静默安装，也不会更新商业插件。

## 本地数据与应急恢复

数据目录：%LOCALAPPDATA%\ResolvePluginManager。包括设置、词库、翻译缓存、候选目录、禁用备份、翻译备份及更新包。密钥只在当前会话使用，不保存到配置，不上传到 GitHub。

应用后，原模块位于同目录的 原名.ofx.rpm-original，译文位于 原名.ofx.rpm-translations.tsv，记录位于 原名.ofx.rpm-state.json。另有 SHA-256 校验备份，位于本地数据目录的 translation-backups。

如果管理器无法启动：退出所有宿主，备份当前目录，把适配层 .ofx 移到别处，将对应 .ofx.rpm-original 改回原 .ofx 名称。原位置已有原厂更新文件时不要覆盖。

软件不包含或上传商业插件、许可证或破解逻辑。只在点击翻译时将英文候选发送到所选服务。在线服务的可达性、额度和准确性由服务商决定。完整限制、接口来源、构建和发布步骤见 README。
